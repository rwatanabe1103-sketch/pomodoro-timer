# 🛍 EC サイト向けチャットボット（ハイブリッド型・デモ）

自社 EC サイトに設置するチャットボットのプロトタイプです。
**FAQ（ルールベース）で定番質問に即答**し、対応できない質問だけ
**Claude API（AI）にフォールバック**する構成です。

## 仕組み

```
ユーザーの質問
   │
   ▼
① FAQ マッチング ──ヒット──▶ 即答（APIコスト不要）
   │ ヒットしない
   ▼
② Claude API（claude-opus-4-8）が商品データ・FAQ を踏まえて回答
   │ APIキー未設定 / 失敗
   ▼
③ サポート窓口を案内
```

回答には `FAQ` / `AI` / `案内` のラベルが付き、どの経路で答えたか分かります。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `app.py` | FastAPI バックエンド（`/api/chat` エンドポイント） |
| `faq.py` | FAQ のキーワードマッチング |
| `data/faq.json` | FAQ データ（配送・返品・支払いなど） |
| `data/products.json` | サンプル商品データ |
| `static/index.html` | デモ用 EC ページ＋チャットウィジェット |

## 使い方

```bash
cd chatbot
pip install -r requirements.txt

# AI フォールバックを使う場合は API キーを設定（任意）
export ANTHROPIC_API_KEY="sk-ant-..."

uvicorn app:app --reload
```

ブラウザで http://127.0.0.1:8000 を開き、右下の 💬 ボタンからチャットを試せます。

> **APIキーは任意です。** 未設定でも FAQ 部分は動作し、AI が必要な質問には
> サポート窓口の案内が返ります。まず FAQ だけで動きを確認し、後から AI を有効化できます。

## 試せる質問の例

- 「送料はいくらですか？」→ **FAQ** が即答
- 「返品はできますか？」→ **FAQ** が即答
- 「ワイヤレスイヤホンの在庫はありますか？」→ **AI** が商品データから回答（要APIキー）

## カスタマイズ

- **FAQ を増やす**: `data/faq.json` に `keywords` / `question` / `answer` を追加。
- **商品を差し替える**: `data/products.json` を自社商品に置き換え（本番では DB や
  商品APIから動的に読み込む形に拡張するのがおすすめ）。
- **応対トーンを変える**: `app.py` の `SYSTEM_PROMPT` を編集。

## 本番化に向けた次のステップ（参考）

- 商品・在庫データを実際の DB / 商品 API と連携（リアルタイム在庫）
- 会話履歴の保持（マルチターン対応）とセッション管理
- 回答のストリーミング表示
- 既存サイトへの埋め込み（ウィジェットの JS 化）と CORS 設定
- ログ・分析、エスカレーション（有人チャットへの引き継ぎ）
