# フクロウチラシ A4 2面付け 両面 入稿データ

A5表裏のチラシ（フクロウフィギュア付き観葉植物）を、A4横に2枚並べて2面付けした
プリントパック入稿用の両面PDFです。A4で印刷後、中央で断裁してA5チラシ2枚にします。

## 成果物

- `フクロウチラシ_A4面付_両面_入稿用.pdf` … 入稿用PDF（2ページ / 1p=表, 2p=裏）
- `impose.py` … 面付け生成スクリプト（PyMuPDF）

## 仕様

| 項目 | 値 |
|------|----|
| 用紙 | A4 横（仕上がり 297×210mm） |
| 面付け | 同一チラシを左右に2面（A5 148×210mm ×2） |
| データサイズ | 319×232mm（仕上がり + 塗り足し3mm + トンボ8mm） |
| 塗り足し | 四辺3mm |
| トンボ | 角トンボ（外周4隅）＋ 中央上下に断裁ガイド |
| 面付けの継ぎ目 | 中央でトリム同士を突き合わせ（隙間・重なりなし） |
| ページ | 1=表面, 2=裏面（天地そろえ／左右反転なし） |
| カラー | RGB（元データ準拠。プリントパックでCMYK自動変換） |
| フォント | 全文字アウトライン化済み（フォント埋め込み0） |

## フォントについて（重要）

元のA5データは文字が **Type3フォント** で作られており、プリントパックの
プリフライトで「埋め込まれていないフォントが含まれます(20493)」エラーになりました。
対策として **Ghostscript(`-dNoOutputFonts`) で全文字をアウトライン化** しています
（画像はロスレス保持・ダウンサンプルなし）。出力PDFのフォント数は0です。

- アウトライン化元データ: `source_outlined.pdf` を生成 → それを面付け
- 生成: `impose_outlined.py`（両面1ファイル）, `impose_split_outlined.py`（表裏別＋トンボ有無）

## 安全余白版（*_safe.pdf）

元デザインは上下（タイトル・フッターのYAMATOロゴ/住所）が仕上がり線から約1〜2mm
しかなく、断裁ズレで切れるリスクがあったため「安全余白版」を追加。

- デザイン内容を約95%(S=0.95)に縮小し、上下左右に安全余白（下端の文字で約6mm、左右約4mm）を確保
- 縁の塗り足しは端ピクセル延長で自動生成（帯は端まで届く見た目を維持）
- 下端はフッターが白地のため白で延長（ロゴの尾引き防止）
- 全面を約400dpiにラスタライズ → 72dpi低解像度警告も解消、フォント0
- 生成: `make_safe_source.py`（安全版元データ source_safe.pdf を作成）→ `impose_split_safe.py` で面付け
- ファイル: `fukurou_A4menzuke_{omote,ura}_{tombo,notombo}_safe.pdf`

## 断裁について

- プリントパックはA4仕上がり（外周のトンボ）で断裁します。
- 中央のA5×2への断裁は、中央上下の断裁ガイドに沿って行ってください。
- 左右は同一デザインのため、両面の左右位置ずれは影響しません。

## 生成手順

```bash
python3 impose.py
```

入力元PDF（A5+塗り足し3mmの2ページ）を面付けして出力します。
入力パスはスクリプト冒頭の `SRC` を編集してください。
