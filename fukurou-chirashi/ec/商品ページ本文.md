## ■ 冒頭（3ページ共通）― シリーズのご紹介

### 緑のそばに、ちいさな福を。 ― FUKURŌ × INTERIOR GREEN

「FUKURŌ（フクロウ）× INTERIOR GREEN」は、暮らしに寄りそう観葉植物に、2羽のフクロウのフィギュアをそっと添えたシリーズです。

フクロウは古くから「不苦労（苦労知らず）」「福来朗（福が来る）」の語呂にちなみ、“福を呼ぶ縁起のよい鳥”として親しまれてきました。枝や鉢のふちにちょこんと寄り添う2羽のフクロウが、緑のある毎日に、小さな物語とやすらぎ、そしてちいさな福を運びます。

生産者としての目利きで選んだ元気な株に、職人が一鉢ずつ丁寧に仕立てました。ご自身の暮らしのお供に、また新築や開店のお祝い、大切な方への贈り物にもおすすめです。

## TYPE A｜アイビーのリース仕立て

### 商品について
つる性のアイビーを、やわらかなアーチを描くリース仕立てに整えました。細やかな葉が生み出す曲線は軽やかで上品。光を受けると葉がいきいきと輝き、玄関やリビング、明るい窓辺のアクセントによく映えます。アーチの枝には2羽のフクロウがちょこんと。まるで物語のワンシーンのような、見るたびに心和む佇まいです。

### おすすめポイント
- **アーチが美しいリース仕立て** … 置くだけで様になる、上品で涼やかな樹形。空間を洗練された印象に。
- **2羽のフクロウの物語性** … 枝に寄り添う姿がかわいらしく、来客との会話のきっかけにも。
- **育てやすく生長が楽しい** … アイビーは丈夫で生命力が強く、はじめての方でも安心。伸びていくつるの生長を長くお楽しみいただけます。
- **明るい室内にぴったり** … レースカーテン越しのやわらかな光が差す窓辺で、葉がいきいきと映えます。

### こんな方・シーンに
新築・引っ越しのお祝い、お誕生日の贈り物に。玄関やリビングをやさしく彩りたい方にもおすすめです。

### お手入れ（かんたん）
明るい場所に置き、土の表面が乾いたら鉢底から流れるくらいたっぷりと水やりを。真夏の直射日光と乾燥しすぎだけ気をつければ、元気に育ちます。

## TYPE B｜ガジュマル ― 多幸の木

### 商品について
太くぷっくりとした幹が印象的なガジュマル。“多幸の木・幸せを呼ぶ木”として親しまれる、縁起のよい観葉植物です。丈夫で育てやすく、はじめての一鉢にもぴったり。根元には2羽のフクロウフィギュアを添えて、多幸を願う小さな景色に仕立てました。受け皿付きで、届いたその日からそのまま飾っていただけます。

### おすすめポイント
- **縁起のよい“多幸の木”** … 「幸せを呼ぶ木」と親しまれるガジュマルに、福を呼ぶフクロウ。ダブルの縁起物として贈り物に最適です。
- **とにかく丈夫で育てやすい** … 生命力が強く、少しくらい忙しくても元気。園芸がはじめての方や、久しぶりに植物を育てる方にも安心です。
- **愛らしい幹とフクロウ** … ぷっくりとした幹に2羽が寄り添う姿は、思わず笑みがこぼれる愛らしさ。インテリアのアクセントにも。
- **受け皿付きですぐ飾れる** … 面倒な準備は不要。届いてすぐ、お好きな場所に置くだけです。

### こんな方・シーンに
開店・開業のお祝い、長寿やご栄転のお祝いに。「縁起のよいものを贈りたい」という方にもおすすめです。

### お手入れ（かんたん）
明るい場所に置き、土の表面が乾いたらたっぷりと水やりを。寒さがやや苦手なので、冬は室内の暖かい場所で管理してください。

## TYPE C｜サボテンの寄せ植え

### 商品について
数種類のサボテンを、横長のスリムな鉢に寄せ植えにしました。高低差のある景色に2羽のフクロウフィギュアを添えて、まるで小さな砂漠のワンシーンのように。水やりは少なめでよく、乾燥に強いのでお手入れもかんたんです。省スペースで置けるので、デスクや窓辺、棚の上にもよく似合います。

### おすすめポイント
- **手間いらずでお世話かんたん** … 水やりは控えめでOK。乾燥に強いので、忙しい方や「水やりを忘れがち」という方にもぴったりです。
- **一鉢で楽しむ小さな景色** … 形の異なるサボテンを寄せ植えにし、フクロウを配置。眺めているだけで楽しい、物語のある一鉢です。
- **置き場所を選ばない横長スリム** … 幅のあるスマートな鉢で、デスクや出窓、棚の上など、ちょっとした場所に飾れます。
- **個性を楽しめる** … サボテンの種類や形はひとつずつ表情が異なり、あなただけの寄せ植えに出会えます。

### こんな方・シーンに
気軽な贈り物やちょっとしたプレゼントに。男性やお子さまへのギフト、デスクまわりの癒やしにもおすすめです。

### お手入れ（かんたん）
日当たりと風通しのよい明るい場所に置き、水やりは控えめに。土がしっかり乾いてから与えてください。トゲにはご注意ください。
